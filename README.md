# PolygonScraping
Phase I of the Master Project @ UZH

Environment
-----------

Create a `.env` file with your settings. Example variables:

```
DATABASE_URL=postgres://user:pass@localhost:5432/dbname
FROM_BLOCK=50000000
# Set this to your Subquid / SQD Cloud project endpoint. See docs/app below.
SUBQ_URL=https://your-subquery-or-sqd-endpoint/graphql
```

Where to get `SUBQ_URL`:

- SQD docs: https://docs.sqd.ai/
- SQD Cloud (hosted): https://app.subsquid.io/
